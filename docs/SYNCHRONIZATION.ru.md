# Проверить → Синхронизировать

1. Укажите название задачи, источник и назначение.
2. Нажмите **Проверить**. Настройки сохранятся, появится план.
3. Нажмите **Синхронизировать** и подтвердите план.

Направление только одно: **источник → назначение**.
Новые файлы добавляются. Если после подтверждённой синхронизации изменился
только источник, файл назначения обновляется, а его прежняя версия сохраняется.
Если назначение изменено отдельно или нет надёжной исходной записи сравнения,
файл остаётся конфликтом. Лишние файлы назначения не удаляются.

**Предыдущие версии** открывает сохранённые варианты выбранной задачи.
Восстановление сохраняет выбранный вариант отдельным новым файлом;
существующий файл по выбранному пути не перезаписывается.

Состояние сравнения и предыдущие версии хранятся в `runtime/sync` рядом
с приложением. При переносе приложения нужно переносить весь каталог
`runtime`, а не только `tasks.json`. Проверки не блокируют намеренную подмену
каталогов сторонним процессом. При ошибке уже завершённые файлы сохраняются.

Трей и фоновая синхронизация реализованы: включённые задачи выполняются раз в
минуту или реже и при подключении своего съёмного тома.
[Настройка и ограничения](TRAY_AND_BACKGROUND_CHECKS.ru.md).
Запуск при подключении флешки и двусторонняя синхронизация пока отсутствуют.

Удалённые файлы назначения копируются повторно. Для существующих конфликтов доступен явный выбор источника: [подробнее](REFINEMENTS.ru.md).
