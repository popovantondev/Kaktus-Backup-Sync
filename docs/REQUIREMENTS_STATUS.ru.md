# Сверка требований — 5.2.0-preview.7

Это фактическое состояние, а не заявление о полном завершении продукта.

| Требование | Состояние |
|---|---|
| Создание, проверка и сохранение задач | Реализовано, включая пустой источник и подробности ошибки |
| Выбор в текущей папке и открытие Проводника | Реализовано |
| Односторонняя синхронизация и восстановление удалённого назначения | Реализовано |
| Временная проверенная запись и предыдущая версия | Реализовано |
| `.SyncVersions`, семь версий, восстановление | Реализовано для новых версий; старые локальные версии сохранены отдельно |
| Конфликт и явный выбор источника | Реализовано; невыбранное назначение сохраняется |
| Сравнение размера, даты, хэша и запоминаемое «оставить назначение» | Реализовано; изменение одной из сторон снова показывает конфликт |
| Распознавание переименований | Реализовано для однозначного совпадения размера и SHA-256 с прежней неизменённой копией; неоднозначные дубликаты не переименовываются |
| Общая и отдельная пауза | Реализовано с сохранением настроек |
| Первые пять подтверждений, отключение и сброс | Реализовано |
| Частота проверок | От одной минуты по последующему уточнению; интервал сохраняется сразу |
| Кэш и полная проверка | Фоновые проверки используют кэш, раз в час полное чтение; ручная проверка всегда полная |
| Явная привязка и реакция на флешку | Реализованы событие и проверка идентификатора; нужно физическое испытание |
| Пятисекундный отсчёт USB | Заменён немедленной реакцией без повторных уведомлений по последующему уточнению |
| Новая буква привязанного диска | Реализована для обоих концов; проверены новый путь, чужой том, дубликат номера и отсутствие тома перед записью |
| Занятый файл | Реализован пропуск блокировки с продолжением остальных файлов, записью в историю и повтором при следующем запуске |
| Последний запуск, интервал, следующий запуск | Реализовано в карточках; следующий запуск зависит от ручной работы |
| Ручная и автоматическая история | Реализовано |
| Один экземпляр | Реализовано; старую сборку без защиты следует закрыть |
| Переносный режим | ZIP уже содержит `portable.flag` и среду .NET; настройки рядом с EXE. Проверены запуск и перенос всей папки |
| Версионирование и три копии конфигурации | Реализовано; восстановление повреждённого списка выполняется явно |
| Core без файловой системы | Реализовано |
| MVVM и тонкий код окна | Высокоуровневая координация вынесена в MainViewModel и BackupWorkspace; MainWindow.xaml.cs отвечает за представление и оконные события. MainViewModel всё ещё объединяет много сценариев, поэтому дальнейшая декомпозиция координатора не завершена |
| DE/EN/RU и руководства | Реализовано; подробности ошибок переводятся при смене языка. Для ошибок компонентов показаны переведённая подсказка и код диагностики |
| Ограниченная лицензия | Текущий файл сохранён; история проверена и остаётся локально |
| Публичный GitHub | Локально подготовлен preview.7 с утверждённым маскотом, языковыми скриншотами и разрешённой записью; публичный GitHub ещё не опубликован |
| Финальный релиз | Пока preview; чистая Windows и аппаратные испытания ещё не проверены |

Дополнительно реализованы отмена внутри файла, проверенная промежуточная запись
в `.SyncWork` и изменение только регистра имени файла. Регистр родительских папок
автоматически не меняется. Новые настройки сохраняются в формате 2; старый формат 1
читается автоматически, обратное чтение старой программой не поддерживается.

Проверены полный WPF-сценарий, команды без окна, восстановление после завершения
собственного тестового процесса, искусственные ошибки нехватки места и устройства.
Итоговые числа и пакет: [аудит выпуска](RELEASE_AUDIT.md).
Расширенные проверки интерфейса, DPI, сети и доступности исключены из текущего этапа.
Чистая Windows и аппаратные испытания остаются непроверенными.
