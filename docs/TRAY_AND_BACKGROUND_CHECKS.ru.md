# Трей и фоновая проверка

После запуска окно можно свернуть или закрыть крестиком: оно останется в трее
рядом с часами. Двойной щелчок по значку снова покажет окно. Полное завершение
доступно только через пункт **«Закрыть программу»** в меню значка.

У каждой сохранённой задачи есть настройка **«Проверять в трее»**. Выберите
период 1, 5, 15, 30 или 60 минут и нажмите **«Проверить»**, чтобы сохранить
настройку задачи. По умолчанию фоновая проверка выключена.

Включённая задача автоматически строит план и синхронизирует новые файлы и
безопасные обновления. Конфликты не перезаписываются. Обычное успешное
выполнение не показывает всплывающее окно. Уведомление появляется только при
конфликте или недоступной папке и не повторяется при неизменном результате.

При включении задачи программа сохраняет идентификатор доступного съёмного
тома. После подключения этого же тома она сразу запускает задачу, не ожидая
следующего интервала. Накопитель не отключается и не форматируется. Если
назначенный путь находится на другом томе или флешка подключена под другой
буквой и путь больше не существует, запись не выполняется.

Выключенная задача серая и имеет статус «На паузе». Она не проверяется и не
запускается при подключении флешки. Вручную «Синхронизировать» по-прежнему
можно после просмотра плана и подтверждения.

В меню значка в трее есть **«Запускать вместе с Windows»**. По умолчанию пункт
выключен. Только при его включении программа создаёт запись автозапуска для
текущей учётной записи Windows.

Кнопка **«История»** у задачи показывает локально сохранённые результаты
ручных запусков: время, результат, число изменённых файлов и конфликтов.
