# Проверка паузы и значка трея

## Как поставить задачу на паузу

Выберите задачу слева и нажмите **Пауза**. Изменение сохраняется сразу,
без повторного «Проверить». Для возобновления нажмите **Возобновить**.
Снятие галочки автоматизации у сохранённой задачи также сохраняется сразу.
Если файл уже копируется, его операция завершается, следующие файлы не запускаются.

## Исправленные ошибки

- Значки рисовались в координатах 256×256 на изображении 32×32 без масштабирования.
  Стрелки были обрезаны. Теперь кадры правильно уменьшены и встроены в приложение.
- Вместо четырёх практически пустых кадров — 12 проверенных кадров вращения.
- Зелёная галочка обозначает успешную синхронизацию, а не просто включённую задачу.
  Серый значок — пауза; синий без галочки — ожидание; жёлтый — ошибка/конфликт.
- Пауза сохраняется независимо от доступности исходных папок.
- Задача, поставленная на паузу в очереди, не запускается.
- Ручная операция и фоновая синхронизация не выполняются одновременно.
- Крестик скрывает окно без отмены копирования. Выход из трея запрашивает отмену
  и ждёт завершения текущей операции.
- Стандартный большой информационный символ убран из уведомления.
  Шапка системного уведомления оформляется Windows; её фирменное оформление
  не подтверждено визуальной проверкой настоящего уведомления.

## Подтверждение

WPF-проверка прошла для трёх языков и двух размеров. Проверены запись паузы,
возобновление, запрет записи для остановленной и ожидающей задачи, блокировка
фонового запуска во время ручной работы, видимые пиксели стрелок всех кадров,
12 различных изображений, реальные тики анимации и остановка после успеха.
Флешка пользователя не отключалась; тесты используют собственные временные файлы.
