# Повторная синхронизация, конфликты и значок

- Если файл удалён из назначения, «Проверить» снова предлагает скопировать
  актуальный файл из источника. Сохранённая база сравнения этому не мешает.
- Конфликты существующих файлов по умолчанию пропускаются.
  Выделите нужные строки (Ctrl для нескольких) и нажмите «Взять из источника».
  После подтверждения изменится план. «Синхронизировать» выполнит замены,
  предварительно сохранив прежние версии. Повторная проверка сбрасывает выбор.
- Если файл изменился или появился после проверки, прежний план не перезапишет его.
- Кнопки со значком папки рядом с источником и назначением открывают Проводник.
- Внутри приложения используется векторный DrawingImage из SyncIcon.xaml.
  Для EXE из этого же рисунка создаётся ICO с 9 размерами от 16 до 256 пикселей.
  Windows использует растровые кадры ICO; при малых размерах пиксельная сетка
  неизбежна, но увеличение единственного маленького изображения не требуется.

Проверено: 43 теста; настоящее окно WPF на трёх языках в двух размерах,
разрешение выбранного конфликта без преждевременной записи, обновление файлов
и сохранение прежних версий. Вызов Проводника проверен по коду, без открытия
пользовательских папок в автоматическом тесте.
