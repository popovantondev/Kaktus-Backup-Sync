# Карта проекта Kaktus Backup & Sync

## Канонический проект

Этот каталог является единственным рабочим Git-репозиторием приложения. Его
переименование на уровне папки не меняет историю Git, ветку или относительные
ссылки между исходниками.

| Раздел | Назначение | Переносить при переименовании проекта |
|---|---|---|
| `.git` | История, ветки и настройки Git | Да, только вместе с корнем проекта |
| `src` | Исходный код приложения, Core и Infrastructure | Да |
| `tests` | Тесты | Да |
| `docs`, `tools`, `demo` | Руководства, упаковка и демонстрационные данные | Да |
| `artifacts` | Локальные переносные preview и исходные архивы | Да, не включать в Git |
| `runtime` | Локальные результаты проверок или данные переносного запуска | Да, не смешивать с другим runtime |

## Текущие выпуски

- `Kaktus-Backup-Sync-Portable-5.2-preview.7.zip` — опубликованный переносной архив Windows x64.
- `Kaktus-Backup-Sync-Portable-5.2-preview.7.zip.sha256` — опубликованная контрольная сумма приложения.
- `Kaktus-Backup-Sync-Source-5.2-preview.7.zip` и соответствующий `.sha256` — опубликованный архив исходников и его контрольная сумма.

Файлы перечислены в [опубликованном GitHub-выпуске v5.2.0-preview.7](https://github.com/popovantondev/Kaktus-Backup-Sync/releases/tag/v5.2.0-preview.7). Это предварительный, а не стабильный выпуск; см. его примечания и ограничения проверок.

Ранние preview 1–5 не являются текущими выпусками. Перед перемещением в
`Корзина_на_проверку` обязательно проверить отсутствие в них `runtime/tasks.json`
и `runtime/reports`.

## Пользовательские данные

Переносная программа хранит пользовательские задачи, язык, журнал и кэш рядом с
EXE в `runtime`. Этот каталог нельзя объединять с `runtime` другой версии или
другой программы. В репозитории результаты сборок и тестов также могут находиться
под именем `runtime`, но они не являются пользовательскими настройками, если в
них нет `tasks.json` или `reports`.

Вложенные `runtime` внутри каталогов с названиями `*-check` — результаты старых
тестовых запусков, а не рабочее пользовательское состояние. Они оставлены на месте
и не смешиваются с переносной сборкой.

## Обратимая корзина

`Корзина_на_проверку/Устаревшие_preview_1-5_2026-09-17` содержит распакованные
выпуски и ZIP preview 1–5. Перед переносом было подтверждено, что в них нет
`runtime/tasks.json` и `runtime/reports`. Каталог исключён из Git и ничего из него
не удаляется автоматически.

Непереносные старые выпуски могли использовать `%LOCALAPPDATA%\AntonsBackupManager`.
Это отдельные данные совместимости; переименование каталога исходников не меняет
их и не переносит их автоматически.

## Что намеренно не переименяется

Имена C#-проектов, пространств имён и старое имя локального каталога оставлены
без изменения. Они являются внутренними идентификаторами совместимости, а не
именем видимой программы. Переименование их вместе с папкой проекта не требуется
и может нарушить существующее состояние или ссылки.
