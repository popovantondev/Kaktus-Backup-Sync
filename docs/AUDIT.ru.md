# Аудит Anton’s Backup — 8 сентября 2026

Проверены исходный код, сборка, синтетические тесты и настоящее окно WPF.
Это инженерная проверка текущей версии, не независимая сертификация безопасности.

## Исправлено

- Вместо тесной строки кнопок: боковая панель задач, отдельная область статуса,
  таблица файлов и кнопки с переносом при сужении окна.
- Интерфейс и подтверждения переведены на немецкий, английский и русский.
  Выбранный язык сохраняется после перезапуска.
- Проверка, сохранение и копирование выполняются в фоне. На время операции
  нельзя поменять задачу или папки и получить результат чужого плана.
- Копирование использует именно показанный план. Изменение папок или задачи
  делает его недействительным. Смена папок сбрасывает счётчик подтверждений.
- Добавлена проверка всех новых файлов до начала записи, затем повторная
  проверка каждого файла перед копированием.
- Прерванная операция передаёт список завершённых копий для отчёта.
- Убрана неиспользуемая экспериментальная функция перезаписи существующих
  файлов. Интерфейс копирует только новые файлы.
- Усилены проверки завершающих разделителей пути и ссылок в родительских
  каталогах.
- Добавлен собственный знак из двух стрелок и значок Windows. Код генерации
  значка включён в проект.

## Оставшиеся ограничения

- Это копирование новых файлов, а не полноценная двусторонняя синхронизация.
  Обновление существующих файлов, восстановление версий и расписание ещё
  не реализованы.
- Отмена копирования действует между файлами: текущий файл завершается.
- Операция не является общей транзакцией: уже скопированные файлы остаются
  при прерывании. Внешнее вмешательство во время проверки последнего файла
  может потребовать ручной проверки его состояния.
- Проверки ссылок не блокируют намеренную одновременную подмену каталога
  другим процессом.
- Несколько экземпляров приложения не согласуют запись общего списка задач.
  Для одного списка следует использовать один рабочий экземпляр.
- Системное окно выбора папки следует языку Windows; собственные окна
  подтверждения следуют выбранному языку приложения.
- Другие масштабы Windows, работа со скринридером, отключение диска во время
  записи и аппаратные сбои требуют отдельных испытаний.
