# Проверка правил разработки

Актуальная сверка находится в [таблице требований](REQUIREMENTS_STATUS.ru.md).
Ранее вывод о полном соответствии был преждевременным.

Теперь Core содержит модели и правила без файлового ввода-вывода; файловые адаптеры
перенесены в Infrastructure. Редактор и карточки задач имеют отдельные ViewModel.
В preview.6 координация вынесена в MainViewModel и BackupWorkspace. Главное окно
содержит отображение, жесты и пересылку событий Windows; команды и данные связаны
через WPF. Есть отдельные модели предпросмотра, статуса и предыдущих версий.
Подробности: [архитектура](ARCHITECTURE.md).

Добавлены версии формата настроек, три резервные копии, один экземпляр, журнал
ручных и фоновых запусков, кэш с полной перепроверкой. Публичный текст лицензии
ограничивает права; история проверена, для публикации подготовлен чистый снимок
без неё и без приватных файлов. Исходная история не изменяется.

Наличие тестов не доказывает выполнение всех правил. Проверки на чистой Windows,
при аппаратных сбоях остаются внешней проверкой. Конфликты, однозначные
переименования, регистр имени файла и восстановление после прерывания процесса
покрыты проверками на искусственных данных.
