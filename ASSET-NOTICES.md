# Assets and bundled components

The Kaktus mascot and application/tray icons are project artwork covered by
LICENSE. The original mascot image is included in the public source and used by
the application, startup screen, Explorer icon, tray, and portfolio demo. Its
rendered pixels are unchanged; private generation metadata was removed before
the asset was added to the public source. Icon sizes are generated directly
from this same image. Do not substitute alternate cactus artwork.

`Assets/StartupLeaves.mp3` is a recording supplied by the project author, Anton Popov, who has
confirmed permission to include and redistribute it with the public source and
release package. It is optional at runtime; if absent, the application starts
silently.

Self-contained Windows packages include the .NET runtime's `LICENSE.txt` and
`ThirdPartyNotices.txt`. Keep both files when distributing a package. Test framework
packages are development dependencies and are not shipped in the application.
