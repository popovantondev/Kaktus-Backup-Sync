# Fiktive Demo-Daten

`Source` enthält zwei bewusst erfundene Textdateien. `Destination` bleibt beim
ersten Durchlauf leer. Beide Ordner können in der Anwendung ausgewählt werden,
um zuerst einen Plan und danach eine bestätigte Kopie neuer Dateien zu zeigen.

Bitte keine echten Dateien in diesem Ordner ablegen oder zusammen mit dem
Repository veröffentlichen.
